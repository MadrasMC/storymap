Isometric columns

Turned 45° and squashed to half height, the map's square tiles become diamonds, and the diamonds line up in vertical columns and horizontal rows.

    1Columns

    Point at a tile to see its column and its row.

    Map

    Isometric

    A step east (x + 1) is one column to the right; a step south (z + 1) is one column to the left. From (0, 0) in column 0, a tile x steps east and z steps south is in column x − z.

    Neighbouring columns are half a diamond apart. Storymap draws diamonds 32 pixels wide, so a tile is (x − z) · 16 pixels across.

    2Rows

    Rows work the same way, with a sum: a step east and a step south both go one row down, so a tile is in row x + z. Neighbouring rows are half a diamond's height apart, 8 pixels, so a tile is (x + z) · 8 pixels down. A block one level higher is drawn 16 pixels higher, which makes it (x + z) · 8 − y · 16.

    3Around spawn

    Column 0 holds the tiles where x = z. A world's spawn is on it, so the area explored around spawn has tiles on both sides: columns below 0 as well as above. Rows don't: x + z adds two large positive positions, about 1,024,000 around spawn, far more than the most a block's height takes off.
